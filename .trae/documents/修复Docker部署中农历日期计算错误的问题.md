# 问题分析

在Docker中部署后，公历日期和农历日期对不上的原因是容器使用的是默认的UTC时区，而不是中国的CST时区。这导致日期计算时出现偏移，特别是在处理日期边界时。

# 解决方案

在Dockerfile中添加时区设置，确保容器使用正确的中国时区（Asia/Shanghai）。

## 具体步骤

1. **修改Dockerfile**

   * 添加安装tzdata包的命令

   * 设置时区为Asia/Shanghai

   * 添加TZ环境变量

2. **验证修复**

   * 重新构建Docker镜像

   * 运行容器

   * 测试农历日期计算是否正确

## 技术原理

* Alpine Linux默认使用UTC时区

* 中国使用的是Asia/Shanghai时区（UTC+8）

* 时区差异会导致日期计算出现偏移，特别是在处理凌晨时分的日期时

* 正确设置时区后，日期计算将基于中国标准时间进行，确保农历日期与公历日期的对应关系正确
